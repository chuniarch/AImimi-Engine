# 课程术语索引

下面仅列出课程使用的术语，具体解释见对应课程；不记录个人掌握情况。

- context、句柄 (handle)、context 的「代」(generation)
- 状态机 (state machine)、绑定点 (binding point / target)
- location（attribute location / uniform location）
- CPU 资源 (CPU Resource) 与按 context 的 GPU 表示 (per-context GPU representation)
- Manager、缓存键用对象身份 (identity-keyed cache)
- 失败通道 (failure channel)：特殊返回值、状态查询、错误标志、context 丢失、静默失败
- 故障注入 (fault injection)
- 状态缓存 (state cache)、失效 (invalidate) 与重置 (reset) 的区别
- 扩展 (extension)、能力快照 (capability snapshot)
- 事务式发布 (transactional publish)、owned 清单与回滚 (rollback)
- VAO、默认 VAO、手动接线 (manual vertex input)
- 纹理单元 (texture unit)、sampler、纹理完整性 (texture completeness)、NPOT
- FBO、附件 (attachment)、renderbuffer、completeness
- 取消开关 (AbortController)、取消信号 (AbortSignal)、取消原因 (abort reason)、一次性监听 (`{ once: true }`)、转发 (forwarding)（第 23 课）
- 请求行 / 状态行 (request line / status line)、响应头 (response headers)、正文 (body)、分块传输编码 (chunked transfer coding)、流 (ReadableStream)、MTU（第 24 课）
- 世界坐标 (world space)、相机坐标 (camera / view space)、深度 (depth)、垂直视场角 (fovY)、可见高度、视差 (parallax)（第 32–33 课）
- 歪头 (roll)、方位角 (yaw / azimuth)、仰角 (pitch / elevation)、点积 (dot product)、叉积 (cross product)、arcball（第 35 课）
- 事件 (event)、监听函数 (listener)、事件对象 (event object)、默认动作与 preventDefault、指针 (pointer)、指针编号 (pointerId)、按位与 (&)、组合键 (chorded buttons)、指针捕获 (pointer capture)、隐式捕获 (implicit capture)、touch-action、passive 监听（第 36–38 课）
- 命令 (command)、查询 (query)、GPU 进程 (GPU process)、往返 (round trip)、进门 / 出门（进入、退出 scope）、反馈环 (feedback loop)、ping-pong、前缀和 (prefix sum)（第 39 课）
