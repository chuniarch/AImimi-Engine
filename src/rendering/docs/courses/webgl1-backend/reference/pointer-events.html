指针事件：速查

登记监听、事件对象的字段、拖动的骨架、结束拖动的五种方式、滚轮和两根手指。每条后面是实测过的现象。

登记

元素.addEventListener('事件名', (event) => { … }, 选项)
  • 只是登记，执行完就返回；以后每发生一次，浏览器调用一次，并把事件对象作为参数交进来。
  • 选项 { passive: false }：声明要调用 preventDefault。window、document、html、body 上的 wheel、touchstart、touchmove 默认 passive 为 true，调 preventDefault 不起作用。
  • event.preventDefault()：取消浏览器对这件事的默认动作（右键菜单、滚动页面）。

事件对象的字段

字段意思
type事件名，比如 'pointermove'
clientX、clientY从浏览器窗口左上角量起的位置（CSS 像素），y 向下增大。舞台里的坐标 = clientX − stage.getBoundingClientRect().left
pointerType'mouse'、'touch'、'pen'
pointerId指针编号。鼠标一般不变；每根手指各一个
isPrimary第一根手指是 true，后来的是 false
button这一个事件变化的键：0 左键/手指，1 中键，2 右键；pointermove 时是 −1
buttons此刻按着的键，按位：左 1，右 2，中 4。查右键：(buttons & 2) !== 0
deltaY、deltaMode、ctrlKeywheel 事件：往下滚为正；单位 0 像素、1 行、2 页；触控板捏合时 ctrlKey 为 true

事件

  • pointerdown / pointermove / pointerup：一次拖动 = 1 个 down、很多个 move、1 个 up。没按键划过也有 move（buttons 0）。
  • 组合键：第一个键按下以后，别的键按下、松开都只发 pointermove（看 button、buttons），不发 down/up。先松开第一个键时，它没有 pointerup。
  • contextmenu：右键之后发，默认弹菜单。
  • pointercancel：浏览器认定这个指针不会再发事件（touch-action 不是 none 时，浏览器把手指的滑动拿去滚动页面）。
  • lostpointercapture：捕获解除。pointerup、pointercancel 之后自动来一次。
  • wheel：滚轮、触控板滑动、触控板捏合。

拖动的骨架（第 37 课第 3 版）

let dragId = null, lastX = 0, lastY = 0      // 状态放在监听函数外面
pointerdown：if (dragId !== null) return
             dragId = event.pointerId; lastX/lastY = clientX/Y
             stage.setPointerCapture(event.pointerId)   // 拖出元素也照样送来
pointermove：if (event.pointerId !== dragId) return
             dx = clientX − lastX；lastX = clientX；…用 dx、dy
结束：pointerup、pointercancel、lostpointercapture、window 的 blur → 同一个 end
      end 先查编号：已经结束过就什么都不做
另外：每次 pointermove 检查 (buttons & 开始的键) === 0，处理组合键

两根手指（第 38 课）

  • CSS touch-action: none：页面的滚动、缩放不能用 preventDefault 取消，只能事先这样声明。
  • 手指按下时浏览器自动捕获（隐式捕获）。
  • 用 Map 存「指针编号 → 上一次的位置」。
  • 缩放 ×= 移动后两指距离 ÷ 移动前两指距离；中点挪这根手指位移的一半。
  • 项目的轨道控制只认 isPrimary 的指针，所以没有双指缩放。
