浏览器事件从零开始：按一下鼠标，浏览器交来什么

轨道控制要知道四件事：你按了哪个键、指针在哪、它怎么移动、什么时候松开。浏览器用「事件」把这些告诉我们。这一课从「登记一个函数」开始，一共三段代码，每段都挂在一块真实的灰色舞台上运行。页面上显示的代码就是正在运行的那一份，你在舞台上按、拖，下面会逐条记下浏览器交来的东西。

1. 事件是什么

你在页面上按下鼠标的那一刻，浏览器做两件事：

  1. 新建一个对象，把这件事的细节写进去：在哪里按的、按的是哪个键、是鼠标还是手指……这个对象叫事件对象 (event object)。
  2. 找到事先「登记」在这块元素上的函数，一个一个调用，把事件对象当作参数交给它们。这些函数叫监听函数 (listener)。

我们写代码只需要做一件事：登记。写法是：

元素.addEventListener('事件名', 监听函数)
  • 元素：页面上的哪一块。这一课里是灰色的舞台 stage。只有发生在这块元素上的事件，才会交给它身上登记的函数。
  • 事件名：一个字符串，说明关心哪一种事。'pointerdown' 是「指针按下」。指针 (pointer) 是鼠标、手指、触控笔的统称：浏览器用同一套 pointer 事件描述它们。
  • 监听函数：浏览器调用它时，传进来一个参数，就是事件对象。

登记完，代码就执行完了，不会停在那里等。以后每发生一次这种事，浏览器就调用一次那个函数。

5. button 和 buttons

这两个字段名字只差一个 s，回答的是两个不同的问题（Pointer Events 规范 4.1.1.2、4.1.1.3 节）：

  • button：这一个事件「变化」的是哪个键。pointerdown 时是刚按下的那个键，pointerup 时是刚松开的那个键：0 左键（手指、笔尖也是 0），1 中键，2 右键。pointermove 时没有键发生变化，就是 −1。
  • buttons：此刻「按着」哪些键。一个数同时表示几个键，每个键占一位：左键 1，右键 2，中键 4。同时按着左键和右键，就是 1 + 2 = 3。

「每个键占一位」是指二进制的一位。把 buttons 写成三位二进制（第三段代码的记录里已经写出来了）：

buttons = 0 → 000   什么都没按
buttons = 1 → 001   左键
buttons = 2 → 010   右键
buttons = 4 → 100   中键
buttons = 3 → 011   左键 + 右键

想知道「右键现在按着没有」，就看右边数第二位是不是 1。JavaScript 的 &（按位与）一位一位比较两个数，两边都是 1 的位才留下 1：

buttons & 2：
  3 & 2 → 011 & 010 = 010 = 2   不是 0：右键按着
  1 & 2 → 001 & 010 = 000 = 0   是 0：右键没按

所以项目里写 (event.buttons & requiredButtons) === 0（mountOrbitCameraInput.ts:263），意思是「开始拖动的那个键已经不按着了」。

6. 同时按两个键

答案是只有一个。规范规定，第一个键按下以后，再按、再松别的键，浏览器不再发 pointerdown、pointerup，而是发一个 pointermove，由 button 和 buttons 的变化告诉你发生了什么（规范 4.1.1.1 节「Chorded button interactions」）。我在无界面 Chrome 里用 DevTools 协议发真实的鼠标操作，记下的是这样（你自己做一遍，应该看到同样的序列）：

第二行和第三行最值得看：

  • 按下右键：pointermove，button = 2（变化的是右键），buttons = 3（现在左右都按着）。
