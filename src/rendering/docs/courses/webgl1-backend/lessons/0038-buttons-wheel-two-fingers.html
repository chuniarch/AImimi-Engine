1. 第 1 步：右键旋转，和「键松开了却没有 pointerup」

左键拖动挪方块，右键拖动转方块。用一个状态变量 mode 记住这次手势是哪一种，pointerdown 时按 button 决定（第 36 课：0 左键，2 右键）。

还要处理第 36 课第 6 节的问题：按着左键时再按右键，然后先松开左键，浏览器不发 pointerup，只发一个 buttons 变成 2 的 pointermove。所以 pointermove 里要检查：开始手势的那个键，还在 buttons 里吗？用 bit 记下那个键的位（左键 1，右键 2），检查 (event.buttons & bit) === 0。

试试：

  • 左键拖、右键拖：一个挪，一个转。
  • 按住左键 → 按下右键 → 先松左键。记录里会出现「开始手势的键已经松开」，手势结束了。这时再晃鼠标（右键还按着），方块不动。没有合适的鼠标就点「合成：组合键」，它按同样的顺序造出这几个事件。
  • 如果删掉检查那三行：左键松开以后，你按着右键晃鼠标，方块还会被「左键」拖着走。

2. 第 2 步：滚轮

滚轮发的是 wheel 事件。要用的字段有三个：

  • deltaY：这次滚了多少。往下滚是正数，往上滚是负数。「往下滚」指的是页面往下滚、露出下面的内容：规范只按这个方向定义，y 轴朝页面底部为正（W3C Pointer Events 规范）。手指或滚轮往哪边拨才算往下滚，由系统设置决定，例如 macOS 的「自然滚动」开着和关着时方向正好相反；可以在下面的实验台上切换这个设置，比一比同一个手势的 deltaY 正负。鼠标滚一格常见的是 100 左右，但不同系统、不同鼠标不一样（Mac 上还会随滚动速度变化），下面的实验台会显示你的鼠标给多少；触控板一滑，会连续发很多个小的。
  • deltaMode：deltaY 的单位，0 像素、1 行、2 页（MDN）。大多数时候是 0，但读之前要先看它。
  • ctrlKey：按着 Ctrl 滚，是 true。另外，在触控板上做「双指捏合缩放」时，浏览器也发 wheel 事件，并把 ctrlKey 设成 true（MDN）。

滚轮在页面上的默认动作是滚动页面。在舞台上滚，我们要缩放方块，不要页面跟着滚，所以调用 preventDefault。这里有一个细节：addEventListener 的第三个参数 { passive: false }。passive 的意思是「我保证不调用 preventDefault」，浏览器因此不用等函数执行完就能开始滚动。登记在 window、document、html、body 上的 wheel 监听，passive 默认是 true，调用 preventDefault 不起作用；登记在别的元素上默认是 false（MDN：addEventListener）。舞台不属于前一种，可明确写 false 更清楚：「我一定要能取消」。项目也这样写（mountOrbitCameraInput.ts:314）。

试试：鼠标滚一格看 deltaY；用触控板慢慢滑、快快滑，看每个事件的 deltaY；在 Mac 触控板上两指捏合，看 ctrlKey。缩放用的是第 34 课的 e 的若干次方：往上滚一格放大 1.105 倍，往下滚一格缩小同样的比例。

3. 第 3 步：两根手指

3.1 手指也是指针

触摸屏上，每根手指都是一个指针：

  • pointerType 是 'touch'；手指按下时 button 是 0，按着时 buttons 是 1。
  • 每根手指有自己的 pointerId。两根手指，就是两串交错到来的事件：指针 21 的 move、指针 22 的 move、指针 21 的 move……
  • 第一根按下的手指，isPrimary 是 true，后来的是 false。
  • 隐式捕获：手指按下时，浏览器自动把这个指针捕获到按下的元素上，不用我们调用 setPointerCapture（规范 4.1.3 节）。第 37 课的代码照样调用，不冲突。

同时跟踪好几个指针，第 37 课那一个 dragId 就不够了。改用一张表 pointers：键是指针编号，值是它上一次的位置。JavaScript 的 Map 就是这种「键 → 值」的表：set(键, 值) 存，get(键) 取（没有就是 undefined），delete(键) 删（删到了返回 true），size 是条数。

3.2 touch-action：不让浏览器接手

手指在页面上滑，浏览器的默认动作是滚动页面、双指缩放页面。和滚轮不同，这个默认动作不能用 preventDefault 取消：规范规定，页面的平移和缩放只能事先用 CSS 的 touch-action 声明（规范「Declaring direct manipulation behavior」一节和 pointercancel 一节）。

  • touch-action: auto（默认）：浏览器可以在这块元素上滚动、缩放页面。一旦它决定接手，就给你发一个 pointercancel，这个指针之后的事件就不再来了。
  • touch-action: none：这块元素上的手指，浏览器一概不接手，事件全部交给你。

3.3 两指缩放的数学

两根手指张开，方块变大；捏拢，变小。放大多少倍？用两指之间的距离之比：

  • 一次 pointermove 只报告一根手指的新位置，另一根不动。设动的这根从 A 移到 A'，另一根在 B。
  • 移动前两指距离 before = |A − B|，移动后 after = |A' − B|（|…| 是长度，用 Math.hypot 算）。
  • 缩放乘上 after ÷ before。比如两指从相距 100 px 张开到 140 px，就乘 1.4。
  • 两指的中点 (A + B) ÷ 2 变成 (A' + B) ÷ 2，挪了 (A' − A) ÷ 2，也就是这根手指位移的一半。方块跟着中点挪 dx/2、dy/2。

为什么用比值而不用差值？和第 34 课一样：比值每一步相乘，张开再捏回原来的距离，缩放正好回到原来的大小。

4. 合起来：完整的最小例子

把第 37 课第 3 版和本课三步合在一起，就是上一轮那份「完整的最小实例」，这次每一行都有注释。舞台上：左键或一根手指拖动，右键旋转，滚轮或两根手指缩放。

合成按钮造出来的手指事件，和真手指的字段一样（pointerType 是 'touch'，各有 pointerId），只是浏览器不会为它们发 lostpointercapture。真实触摸是什么样，看我在无界面 Chrome 里用 DevTools 协议录下的两指捏合：

5. 对照项目代码

项目的 mountOrbitCameraInput 比这个最小例子少了两样，多了三样：

  • 没有双指缩放。pointerdown 第一行就是 if (closed || drag !== null || !event.isPrimary) return（:234）：第二根手指 isPrimary 是 false，直接忽略。所以在触摸屏上，HW2 只能一根手指转动，不能捏合缩放。HW2 主要在电脑上用，这是一个取舍。
  • 没有转方块，而是转相机。左键是 rotate（第 35 课的两个角），右键是 pan（第 33 课），滚轮是第 34 课的缩放。
  • 右键只认鼠标：event.button === 2 && event.pointerType === 'mouse'（:238）。触控笔的侧键 button 也是 2，项目不让它平移。
  • 拖动途中换了相机就结束手势（:262）：HW2 切换预设相机时，不能把旧相机的拖动接到新相机上。
  • context 丢失也结束手势（:317）。
